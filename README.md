# SKHEBO Portfolio

A clean, deployable portfolio website for the SKHEBO ecosystem.

## Overview

This project presents the SKHEBO ecosystem as a digital brand and innovation hub. It highlights the main flagship repository, the personal learning system, and the portfolio structure of the broader SKHEBO identity.

## Included projects

- SKHEBO-PROJECTS: flagship ecosystem hub
- K-Eye-V1: personal system for observation, adaptation, and learning
- SKHEBO-PROJECTS...: likely duplicate or variant record of the main project

## Website structure

- `index.html` — landing page and project content
- `styles.css` — full visual styling and responsive layout
- `script.js` — small JavaScript enhancement for dynamic footer year
